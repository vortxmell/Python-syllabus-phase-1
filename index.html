MODULE 1 Getting Started with Python
✍️ Writing Code ▼
📌 Apa itu Programming?

Programming adalah cara kita bagi arahan kepada komputer. Komputer buat apa yang kita suruh — satu baris satu baris dari atas ke bawah.

📌 print() — cara output ke screen
print("Hello World")
print("Nama aku Mel")
# Output: Hello World
# Output: Nama aku Mel
📌 Rules penting
  • Python sensitive kepada huruf besar/kecil — Print vs print adalah berbeza
  • String mesti dalam tanda petik — "Hello" atau 'Hello'
  • Kod jalan dari atas ke bawah — baris pertama dulu
💡 Tip: Bila ada error, baca error message dari atas — dia akan bagitau kat baris mana masalahnya.
📦 Memory & Variables ▼
📌 Apa itu Variable?

Variable adalah bekas untuk simpan data. Macam kotak berlabel — kau letak sesuatu dalam kotak, pastu panggil nama kotak tu untuk ambil balik.

📌 Cara buat variable
nama = "Mel"
umur = 20
tinggi = 1.75

print(nama) # Output: Mel
print(umur) # Output: 20
📌 Rules penamaan variable
  • Guna nama yang bermakna — nama_pekerja bukan x
  • Boleh guna huruf, nombor, underscore (_)
  • Tak boleh start dengan nombor — 1nama ❌
  • Tak boleh ada space — guna underscore: nama_penuh
  • Case sensitive — Nama dan nama adalah berbeza
📌 Reassigning variable
points = 35
points = 45 # nilai lama dilupakan
print(points) # Output: 45
💡 Variable boleh update — nilai baru replace nilai lama.
📝 Text Data (String) ▼
📌 Apa itu String?

String adalah data jenis teks. Mesti dibungkus dengan tanda petik — boleh guna petik tunggal '...' atau petik berganda "...".

📌 Contoh String
nama = "Ahmad Mel"
mesej = 'Hello World'
nombor_string = "123" # ini STRING, bukan int!
📌 String Concatenation — cantum string
first = "Ahmad"
last = "Mel"
full = first + " " + last
print(full) # Output: Ahmad Mel
📌 len() — kira panjang string
nama = "Ahmad"
print(len(nama)) # Output: 5
⚠️ Nak cantum string dengan nombor — kena convert nombor ke string dulu guna str()
🔢 Numerical Data (Int & Float) ▼
📌 Dua jenis nombor dalam Python
TypeMaksudContoh
intNombor bulat10, -5, 0, 100
floatNombor perpuluhan3.14, -1.5, 0.0
📌 Operasi matematik
# Operasi asas
print(10 + 5) # 15 — tambah
print(10 - 3) # 7 — tolak
print(4 * 3) # 12 — darab
print(10 / 3) # 3.33 — bahagi
print(10 // 3) # 3 — bahagi bulat
print(10 % 3) # 1 — baki (modulo)
print(2 ** 3) # 8 — kuasa
💡 int + int = int. int / int = float selalu. Guna // kalau nak hasil bulat.
⚙️ Working with Variables ▼

✅ Standards & Best Practices ▼
📌 Clean Code Rules
  • Nama variable meaningful — gaji_pokok bukan g
  • Satu variable, satu tujuan — jangan guna balik variable untuk benda lain
  • Indentation konsisten — Python wajibkan ini
  • Komen untuk explain WHY — bukan WHAT
📌 Cara tulis komen
# Ini komen satu baris

# Explain WHY — bagus:
# Kena convert ke float sebab gaji ada sen
gaji = float(input())

# Explain WHAT — kurang bagus:
# convert input ke float
gaji = float(input())

🧠 Logical Operations (and, or, not) ▼

CONTROL FLOW Control Flow — Loops & Selection
🔀 Control Flow Basics ▼
📌 3 Teknik Control Flow
TeknikMaksudContoh

IterationUlang blok kod beberapa kalifor loop, while loop
SelectionPilih mana kod nak jalan berdasarkan conditionif / else
📌 Algorithm

Algorithm = set of step-by-step instructions untuk selesaikan masalah. Boleh ditulis dalam: Natural Language, Pseudocode, atau Flowchart.

💡 Semua program — dari calculator sampai AI — adalah gabungan tiga teknik ni je.
🔁 For Loops ▼
📌 Syntax asas
for i in range(5):
    print(i)
# Output: 0, 1, 2, 3, 4
📌 range() — start dari 0, bukan 1
range(5) # 0, 1, 2, 3, 4
range(1, 6) # 1, 2, 3, 4, 5
range(0, 10, 2) # 0, 2, 4, 6, 8 (step 2)
📌 Multiple statements dalam loop
for i in range(3):
    print("Item ke-" + str(i))
    print("---")
# Semua baris dalam loop kena indent sama
⚠️ Kena ada colon : dan indentation. Tak ada indent = kod tu tak masuk loop.
🔄 While Loops ▼
📌 Syntax asas
counter = 0
while counter < 5:
    print(counter)
    counter = counter + 1
# Output: 0, 1, 2, 3, 4
📌 Bila guna for vs while?
Guna forGuna while
Tahu bilangan iterationAda condition — loop sampai condition False
Loop through list/rangeTunggu user input yang betul
📌 Guna input() dalam while loop
jawapan = ""
while jawapan != "ya":
    jawapan = input("Setuju? ")
print("Terima kasih!")
⚠️ Mesti ada counter atau condition yang akan jadi False — kalau tak, infinite loop!
🎯 Selection — If / Else ▼
📌 Syntax asas
if condition:
    # jalan kalau condition = True
    print("True!")
else:
    # jalan kalau condition = False
    print("False!")
📌 Logical Operators: and, or
# and — KEDUA-DUA kena True
is_student = False
age = 16
print(is_student and (age < 18)) # False
# False sebab is_student = False — Python stop sini (short-circuit)

# or — MANA-MANA SATU kena True
age = 32
is_student = True
print(age < 18 or is_student) # True
📌 Else boleh skip kalau tak perlu
age = 16
if age < 18: print("Apply Discount")
print("Proceed to payment") # jalan always
💡 Lepas if-else selesai, sequence sambung seperti biasa — baris luar block jalan sentiasa.
🌳 elif & Nested If-Else ▼
📌 elif = "else if" — check lebih banyak condition
age = 75
if age < 18:
    print("Junior discount")
elif age >= 75:
    print("Senior discount")
else:
    print("No discount")
📌 Urutan if → elif → else KENA BETUL
  • Python check dari atas ke bawah — yang pertama True akan jalan
  • if mesti dulu, elif lepas tu, else paling last
  • Boleh ada banyak elif tapi satu if dan satu else je
📌 Nested If-Else — if dalam if
if age < 18:
    if is_student:
        print("20% discount")
    else:
        print("10% discount")
else:
    print("Regular price")
📌 Indentation tunjukkan level nesting
  • Level 1 indent = dalam if pertama
  • Level 2 indent = dalam if yang nested
  • Variable kena declare dulu sebelum guna dalam if — kalau tak, error NameError
💡 Baca flowchart dari kanan ke kiri, bawah ke atas untuk faham nested logic dengan mudah.
